# PR #642 independent audit

Date: 2026-09-01

Scope: issue #616's Workspace authorization/renewal terminology and regression evidence.

## Verdict

PASS. The client contract now distinguishes transport retries from authorized mutation attempts. Client and real-router tests jointly prove that an expired bearer can cause two transport POSTs while only the renewed request reaches Workspace command execution.

## Evidence

- `HttpEngineBus` performs one stale-bearer POST, renews once, resolves the fresh bearer, and performs one post-renewal POST with the same command body.
- The client test records exactly one authorized mutation attempt and does not replay 409 or other non-401 responses.
- The Engine test sends the same valid command first with a stale token and then with the valid token through the production router.
- After the unauthorized request, Workspace remains at revision 0. After the authorized request, it advances to revision 1 with exactly one history entry.
- Authentication middleware rejects the stale request before the Workspace endpoint can execute.
