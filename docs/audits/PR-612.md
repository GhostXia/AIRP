# PR #612 independent audit — accepted Workspace controls

Date: 2026-08-28

Audited commit: `9398ff26bb82fae62c2ab2f5d0aac96409b4529f`

Scope: #577 PR 10e, Vue accepted-only Workspace controls and responsive saved
split ratios.

## First review — fail

The first independent review blocked the candidate on two high-severity races:

1. Bus reconstruction briefly exposed a new Bus with the previous user scope.
2. A slow Workspace GET could replace a newer command response.

It also requested exact command-sequence and 760/761px browser evidence, plus
clear pending/focus semantics for tabs.

## Resolution

- A candidate Bus remains private until scope resolution, Workspace load,
  session listing, and Surface connection have all completed. The published
  Bus and scope are cleared throughout initialization, and Workspace controls
  remain disabled.
- Manual Workspace reads and commands on the published Bus share an operation
  epoch. Initialization reads are separately bound to an unpublished candidate
  and guarded by Bus attempt identity. Bus invalidation, scope initialization,
  and unmount invalidate prior published operations. The accepted store also
  rejects revision rollback.
- Tabs separate local roving focus from Engine-accepted selection and expose
  busy/disabled semantics while a command is pending.
- The real-Engine browser smoke now asserts the exact three-command sequence,
  CAS revisions, saved 65/35 to 70/30 rendering, and the 760/761 CSS-pixel
  responsive boundary.

## Second review — pass
