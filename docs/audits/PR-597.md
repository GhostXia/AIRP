# PR #597 independent audit

Date: 2026-08-26  
Scope: `codex/593-writer-cas` against `origin/main`  
Auditor: independent Terra audit agent  
Final verdict: **PASS**

## Initial blocking findings

The first audit failed the change for three reasons:

- the revision captured before prompt assembly was not the revision of the
  exact state snapshot later rendered into the model prompt, allowing false
  conflicts after an intervening mutation;
- Agent finalization logged and swallowed post-message CAS failures, then
  incorrectly emitted a converged result;
- the optional Surface read could treat history-only data without `live.json`
  as a committed empty object.

The continuation audit then found one additional blocker: revision-0 legacy
`live.json` bytes were not parsed before whole-state replacement, so malformed
user state could be overwritten by a CAS write expecting revision zero.

## Resolution and verification

Prompt-state rendering and model finalization now share one locked
`read_surface_state_optional` result: the rendered value and its revision cannot
come from different observations. Model and Agent whole-state writes use
`replace_if_revision`; stale revisions return conflict. Agent state reads expose
`{revision, updated_at, state}`, updates require `expected_revision`, and Agent
finalization emits `finalization_error` instead of a false converged result.

Missing `live.json` remains distinct from a committed empty object. Before any
whole-state CAS replacement, an existing legacy live file is parsed under the
same character/state locks; malformed bytes are preserved and no pointer or
immutable revision is created.

The same auditor re-scanned the latest diff and verified that all blockers were
closed. Local validation passed:

- `cargo test --workspace --all-targets --locked`;
- `cargo test -p airp-core --lib --locked` with 1,502 passed and 5 ignored;
- `cargo clippy --workspace --all-targets --locked -- -D warnings`;
- formatting and `git diff --check`;
- focused stale-CAS, prompt/revision identity, history-only missing state,
  malformed legacy state preservation, Agent tool, and wire-shape tests.

## Non-blocking follow-ups
