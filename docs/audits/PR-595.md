# PR #595 independent audit

Date: 2026-08-26  
Scope: `codex/593-state-atomic` against `origin/main`  
Auditor: independent Terra audit agent  
Final verdict: **PASS**

## Initial blocking finding

The first audit failed the change because the HTTP state/history handlers,
extension `read:state`, Agent `get_character_state`, and prompt-state injection
still read `live.json` or `history.jsonl` directly. A process interruption after
publishing `current_revision` but before refreshing those mutable projections
could therefore expose stale state indefinitely through those paths.

## Resolution and verification

All production Character State readers now enter `StateService::read_optional`
or `StateService::read_history`, which acquire the character/state locks,
verify and resolve `current_revision`, and repair the mutable projections before
returning. The context-bundle reader, found during the repair scan, was also
closed. Regression tests cover stale projections through HTTP state/history,
extension read intent, Agent state tool, prompt injection, and context export.

The same auditor re-scanned production readers and verified:

- the original bypasses are closed;
- no remaining production `live.json` / `history.jsonl` reader bypasses the
  State service;
- legacy missing-pointer data keeps its revision sequence;
- orphan revision directories remain immutable and are skipped;
- commit-only, live-only, history-only, and old projection-ahead interruption
  states recover to the atomic pointer;
- `cargo test -p airp-core --lib --locked` passed with 1,497 passed and 5
  ignored tests;
- strict clippy, formatting, and diff checks passed.

## Non-blocking boundary

Windows power-loss durability for directory metadata is not proven because the
current standard-library-only `sync_dir` implementation is a no-op on Windows.
This PR claims process-interruption recovery and atomic visibility only; the
baseline and plan explicitly exclude the stronger power-loss guarantee. Track
this boundary after merge under the repository's audit-leftover policy.
