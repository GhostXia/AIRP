# PR #605 independent audit — closed Workspace layout commands

Date: 2026-08-28

Scope: `origin/main...codex/577-workspace-commands`

Verdict: **PASS**

## Independence and method

The audit independently reviewed the current diff under the repository audit
charter. It treated the existing Workspace design and prior implementation as
challengeable, inspected the Rust reducer and persistence boundary, the HTTP
adapter, the machine-readable contract, the TypeScript client, and the added
tests. The auditor made no code changes.

## Findings and resolution

The first pass found one blocker: `open_widget` appended `-node` to an otherwise
valid 124–128 byte `instance_id`, producing an invalid node identifier. The
implementation now reuses `instance_id` as the deterministic placement node ID,
so every valid 128-byte identifier remains usable. The re-audit verified the
boundary test and closed the finding.

The first pass also questioned reducer-local failure atomicity and incomplete
`index` wire semantics. The reducer now applies every command to its own clone
and replaces the caller's layout only on success. Rust, JSON authority, and the
TypeScript client now agree that `index` is omitted or an integer in `0..=32`;
explicit `null` is rejected and Rust serialization omits `None`. Tests cover the
omitted, maximum, null, and over-limit cases.

The re-audit additionally verified that moving the active Widget within the
same Tabs container preserves its active reference, while moving it out or
closing it selects a remaining child. No unresolved blocking or non-blocking
code findings remain.

## Verified properties

- all six commands use one locked expected-revision CAS path and publish only a
  fully validated immutable revision;
- failed commands leave both the reducer input and persistent revision
  unchanged;
- `open_widget` accepts only first-party allowlisted Widget types and derives no
  client-controlled executable content;
- `move_widget` preserves placement node identity;
- full Workspace validation enforces identifier, reference, uniqueness, depth,
  node, child, Widget, and document-size limits;
- Rust, `protocol/workspace-v1.json`, and `HttpEngineBus` expose the same closed
  command and Widget-type sets;
- the authenticated HTTP route retains its bounded body and strict unknown-field
  behavior, and the client does not replay conflicts.
